# 香港暑熱指數地圖版設計規格

## 產品目標

以香港地圖呈現十個 HKHI 觀測站的實際分布，並在同一畫面回答目前查看站、全港最高、測站平均及達到 30 的測站數。數據只來自香港天文台最近十組「10 分鐘平均香港暑熱指數」，不插值或生成中間數據。

## 資訊結構

頁面是一張主卡，由上至下分成：

1. 標題、指標簡介及官方數據時間。
2. 左側透明讀數卡與右側香港浮雕地圖，分佔獨立欄位。
3. 臨時數據聲明、觀測站位置及地圖來源。

桌面以地圖作為主要畫面，讀數卡獨立排列在左側，不遮擋地圖；地圖高度按桌面視窗調整，標題、地圖、圖例和來源在一般桌面尺寸內一屏可見。600px 以下改為地圖在上、面板在下。不設排行榜、篩選、縮放、拖曳或詳情頁。

```text
┌──────────────────────────────────────────────────────┐
│ 香港暑熱指數                              更新時間  │
├──────────────────────────────┬───────────────────────┤
│ 目前查看                     │                       │
│ 地名／大型 HKHI              │ 香港浮雕地圖＋十個站點│
│ 全港最高／平均／達 30       │                       │
│ 30 參考線提示                │                       │
├──────────────────────────────┴───────────────────────┤
│ 臨時數據說明                         三項來源署名   │
└──────────────────────────────────────────────────────┘
```

## 地圖與資料

- 香港底圖：香港地政總署數碼地形圖，保留海岸、主要離島、道路及地形；瀏覽器以 SVG 灰階、卷積及柔光濾鏡生成浮雕明暗，並疊回低彩度原圖確保可辨識。
- 投影：地圖由政府 ArcGIS 服務以 WGS84 輸出；底圖與站點使用相同經緯度邊界。
- 密集站點：圓點固定在真實投影位置；滑鼠及觸控按距離選取最近站點，不再為點擊範圍移動圓點。
- 站點：十個固定 metadata 位於 `src/lib/hkhi.ts`。
- 九龍灣：天文台頁面確認 HKHI 站點代號為 ZCP，但未公開精確座標；目前以 CIC-Zero Carbon Park 附近 `22.3266, 114.2078` 暫定定位，程式及介面均明示待核實。
- `Beas River` 顯示為「雙魚河」，與站點座標一致。

## 視覺系統

採用 Apple 介面語言啟發的網頁近似方案，不代表或複製任何官方 Apple 元件。設計以系統字體、霧白中性色、單一藍色互動重點、克制陰影與半透明材質為主；讀數主卡沿用同一張官方地圖作淡灰底紋，上方保留地形細節，下方以無明顯分界的遮罩逐漸模糊並過渡至白色，承托深色摘要文字。卡片沒有另加矩形遮罩或裝飾照片；細邊高光與柔和陰影營造網頁版霧面玻璃質感。右側原地圖保持完整辨識度，紅色只代表達到 30 的警示狀態：

| 角色 | 色值 |
|---|---|
| 背景 | `#F5F5F7` |
| 卡面 | `rgba(255,255,255,.72)`／`#FBFBFD` 後備 |
| 浮雕底色 | `#E8EAED` |
| 分隔線 | `rgba(60,60,67,.16)` |
| 主要文字 | `#1D1D1F` |
| 次要文字 | `#6E6E73` |
| 普通站點 | `#64D2FF` |
| 目前查看 | `#0071E3` |
| 30 或以上 | `#FF3B30` |

標記大小固定，不以 HKHI 數值改變面積。只有作用中的站點顯示地名；完整數值統一在讀數面板顯示。字體優先使用 Apple 平台系統字體，其他平台退回 `PingFang HK` 及 `system-ui`。圓角分為 22 至 28px 的卡面，以及全圓角的時間狀態與按鈕，不混用額外形狀。

系統為深色模式提供獨立中性色及高對比藍色；使用者啟用「減少透明度」或「減少動態效果」時，介面分別改用實色卡面及近乎即時的狀態切換。

## 互動

- 預設查看全港最高站。
- Hover／focus 暫時預覽；離開後返回鎖定站，未鎖定時返回最高站。
- 點擊站點鎖定；再次點擊同站或地圖空白解除鎖定。
- Enter／空白鍵沿用原生 button 點擊；Escape 解除鎖定。
- 每個標記有至少 44×44px hit area、完整 `aria-label`、`aria-pressed` 與 `focus-visible` 外框。
- 選中動畫只使用 220ms 的縮放、顏色及陰影過渡；reduced motion 近乎即時。

## 響應式

- `>= 960px`：讀數卡在左、地圖在右，雙欄留白分隔；地圖尺寸跟隨視窗高度。
- `600 至 959px`：地圖／面板約 3:2。
- `< 600px`：單欄，地圖區約 350px 高，讀數面板在下。
- 不設桌面最低寬度，任何尺寸不得出現水平捲動。

## 數據契約與狀態

- 前端請求同源 `/api/hkhi`，使用 `cache: "no-store"`。
- 首次載入後每 `10 * 60_000` 毫秒更新一次。
- CSV parser 只接受 12 位時間戳、有限數值及分鐘可被 10 整除的記錄。
- 載入時保留地圖與面板骨架；API 失敗顯示既有錯誤訊息及重新載入按鈕，不偽造讀數。
- 地圖資產失敗時顯示地圖錯誤訊息，但讀數面板仍可顯示資料。
