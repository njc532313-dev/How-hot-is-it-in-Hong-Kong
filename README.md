# 香港有幾熱？數據可視化
1.三種溫度測量方法
採用知識卡片的方式，展示幹球溫度，黑球氣溫，濕球氣溫三種溫度測量方法，以及其工作原理解釋
2.全球8月氣溫圖表_1979-2026
这张图根据哥白尼气候变化服务的 ERA5 数据，展示了 1979—2026 年每年 8 月的全球平均地表气温。蓝点表示低于 1991—2020 年 8 月平均值，红点表示高于平均值。2026 年 8 月达到 16.96°C，比基准高 0.85°C，创下有记录以来最热 8 月。
3.最高氣溫折線圖
折線圖呈現香港天文台1926至2026年的年度最高氣溫變化。百年間，最高氣溫由33.6°C升至36.9°C，整體走勢向上，但不同年份仍有明顯波動。圖中著重標示每次刷新歷史紀錄的年份，讀者可滑動或點擊資料點，查看各年的最高氣溫及紀錄日期；1940至1946年因缺乏數據而留白。
4.比較三種熱指標
透過互動圓環圖，呈現自然濕球、黑球及乾球氣溫在大氣溫度、濕球黑球溫度（WBGT）與香港暑熱指數（HKHI）三種測量方式的組成，讓讀者直觀理解三者如何反映環境熱負荷。
5.热压力卷动动画
这段滚动动画以人体为中心，展示热量如何进入身体、由活动产生，以及怎样散出。太阳辐射、气温、湿度和风依次出现，说明远足时的热风险不能只看气温：当身体吸收和产生的热量持续多于散出的热量，热压力便可能增加。
6.香港暑熱指數
這個數據可視化以香港地圖呈現各觀測站最新的香港暑熱指數（HKHI），數據來自香港天文台並每十分鐘更新。使用者可移動或點擊地圖上的站點，查看個別地區讀數，以及全港最高值、測站平均值和達到重要參考線的測站數量，快速掌握香港不同地區的暑熱情況
7.香港暑熱指數快速估算
這個互動式數據可視化工具可快速估算香港暑熱指數（HKHI）。系統會讀取香港天文台京士柏站的即時氣溫，配合使用者輸入的濕度、日照及風勢，呈現當前的暑熱程度與警告門檻。（工具只供教育及初步參考，實際情況應以香港天文台及勞工處公布為準）
