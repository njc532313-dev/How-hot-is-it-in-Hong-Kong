# 比較三種熱指標｜工程交付說明

交付日期：2026-09-24

本工程以互動圓環圖獨立比較乾球氣溫、濕球黑球溫度（WBGT）與香港暑熱指數（HKHI）。

## 文件結構

```text
比較三種熱指標/
├── index.html
└── 交付說明.md
```

## 預覽

在本文件夾執行：

```bash
python3 -m http.server 8766
```

再開啟 `http://127.0.0.1:8766/`。

## 部署

只需部署 `index.html`。工程使用原生 HTML、CSS、JavaScript 與 SVG，不需要圖片資產、npm、建置工具、後端或資料庫。

圓環圖支援滑鼠移入、點擊固定、鍵盤選取、百分比提示、`Esc` 清除及減少動態效果設定。
