# 香港有幾熱？數據可視化｜項目說明

這個文件夾以根目錄的 `香港有幾熱_整合預覽.html` 展示七個與氣溫、熱壓力及香港暑熱指數有關的作品。七個作品的頁面、互動腳本及所需圖片均已收進這一個 HTML；各小項目的獨立 HTML 已移出文件夾。

## 如何預覽

在 macOS 雙擊根目錄的 `開啟整合預覽.command`。它會啟動只在本機運作的預覽服務，並開啟瀏覽器。**請保持終端機視窗開啟**；關閉後，即時資料便不能更新。此入口需要 Node.js 20 或以上版本及網絡連線，使用中的網址會顯示在終端機內。

直接雙擊 `香港有幾熱_整合預覽.html` 可查看靜態圖表及操作大部分互動，但瀏覽器會阻擋兩項即時資料請求：快速估算組件的京士柏氣溫，以及香港暑熱指數地圖的測站讀數。快速估算仍可手動輸入氣溫。

## 七個作品

| 項目 | 內容與資料 |
| --- | --- |
| 香港年度最高氣溫 | 1926–2026 年的年度最高氣溫折線圖，可選取年份並橫向瀏覽。1940–1946 年沒有資料，圖線保留空缺。原始 CSV 保留在 `最高溫折線圖/data/`。 |
| 全球 8 月氣溫距平 | 1979–2026 年各年 8 月的全球平均地表氣溫距平；採用哥白尼氣候變化服務 ERA5 資料，以 1991–2020 年為基準。這是資料快照，往後年份不會自動加入。 |
| 三種溫度測量方法 | 以三張靜態圖文卡解釋乾球氣溫、黑球溫度和自然濕球溫度。原圖片保留在 `三種溫度測量方法/assets/`，整合 HTML 亦已內嵌圖片。 |
| 比較三種熱指標 | 互動圓環圖，比較乾球氣溫、濕球黑球溫度（WBGT）和香港暑熱指數（HKHI）。 |
| 熱壓力捲動動畫 | 向下捲動可依次閱讀汗水蒸發、濕度、氣溫、日照、風及身體活動與熱壓力的關係。原圖片和動畫庫保留在 `熱壓力捲動動畫/`。這是概念圖解，並非健康風險測量工具。 |
| 香港暑熱指數快速估算 | 使用氣溫、相對濕度、環境、日照及風勢作教育用途的 HKHI 估算。經本機預覽入口讀取天文台京士柏氣溫；讀取失敗時可手動輸入。估算並非官方現場儀器讀數，也不能取代官方警告。 |
| 香港暑熱指數地圖 | 以香港地圖呈現天文台各測站的最新 10 分鐘平均 HKHI。讀數屬臨時數據；經本機預覽入口讀取。原 React／Vite 源碼與建置資產保留在 `香港暑熱指數/`。 |

## 文件與維護

- **唯一預覽頁**：`香港有幾熱_整合預覽.html` 已內嵌七個作品，不會因其他文件夾的資料或源碼改動而自動更新。
- **即時資料入口**：`開啟整合預覽.command` 只在 `127.0.0.1` 啟動本機服務，向香港天文台轉發京士柏氣溫及 HKHI CSV 請求；歷史圖表則是靜態資料快照。
- **保留的材料**：CSV、圖片、動畫庫、香港暑熱指數地圖的 React／Vite 源碼與建置資產，以及設計／參考文件仍在各子文件夾。要重新製作整合 HTML，應使用保存的原始 HTML 備份或重新建置對應作品。
- **設計與參考規格**：`香港暑熱指數/DESIGN.md` 及 `香港暑熱指數快速估算/參考資料/design.md` 予以保留；它們不是交付說明。

資料來源以各圖表內的來源標註為準。香港暑熱指數地圖使用香港天文台讀數；部分測站位置為暫定標示，應以官方最新站點資料核實。
