# 香港年度最高氣溫互動折線圖｜工程交付說明

## 1. 交付內容

這是一個無需編譯、無需安裝套件的單頁互動圖表，可直接交給網站搭建人員整合。

```text
最高溫折現圖/
├── index.html                         # 完整可部署頁面，CSS、SVG 與 JavaScript 均已內嵌
├── data/
│   └── CLMMAXT_HKO_yearly_max.csv    # 原始資料，共 107 筆日期紀錄
├── 交付說明.md                        # 本文件
└── 預覽圖表.command                   # macOS 雙擊預覽
```

## 2. 快速預覽

- macOS：雙擊 `預覽圖表.command`。
- 其他系統：直接用瀏覽器開啟 `index.html`。
- 頁面可以在 `file://` 下運作，不需要本地伺服器。

## 3. 部署與整合

### 直接部署

把 `index.html` 上傳為獨立頁面即可。若網站路由要求固定入口名稱，檔案已使用標準的 `index.html`。

### 嵌入現有網站

最穩定的方式是以 iframe 嵌入：

```html
<iframe
  src="/charts/hong-kong-yearly-max-temperature/index.html"
  title="香港年度最高氣溫互動折線圖"
  style="width:100%;height:700px;border:0"
></iframe>
```

若要直接併入既有頁面，請一併搬移 `<article class="card">`、頁首 `<style>` 與頁尾 `<script>`。以下 ID 必須保持唯一：

```text
tempOdo, yearValue, date, live, yAxis, scroller, stage, chart
```

## 4. 資料口徑

- 來源檔：`data/CLMMAXT_HKO_yearly_max.csv`
- 欄位：`Year`、`Date`、`MaxTemperatureC`
- 原始資料：107 筆日期紀錄。
- 圖表資料：94 個有觀測值的年份。
- 同一年若有多個日期錄得相同年度最高溫，圖上合併為一個年度點，日期詳情仍完整保留。
- 1940–1946 年沒有資料，折線刻意中斷，沒有內插。
- Y 軸顯示範圍：32–37°C。
- 創紀錄點：12 個，包括序列起點；最新為 2026 年的 36.9°C。

目前資料已內嵌在 `index.html` 的 `DATA` 常數中；CSV 是來源與日後更新依據，頁面執行時不會讀取外部 CSV。

## 5. 互動行為

- 圖表橫向滑動；滑鼠滾輪與觸控板加入阻尼，滑動停止後吸附到最近年份。
- 滑鼠移入、點擊資料點或使用左右方向鍵，可更新頂部溫度、年份與日期，並在選取點旁顯示「年份 · 溫度」。
- 資料點保留小型實心外觀，但使用較大的隱形感應範圍；點擊會優先鎖定所選年份，不受尚未完成的滑動吸附干擾。
- 頂部溫度採 Odometer/Ticker 滾動動畫。
- 普通年份為橄欖綠實心點；刷新歷史紀錄的年份為深綠實心點；目前選取點為琥珀色。
- 支援 `prefers-reduced-motion`，使用者要求減少動畫時會停用過場。

## 6. 視覺與技術說明

- 圖型骨架：Lieflat Charts F2 Hairline Line。
- 色系：Lieflat Charts Palm 綠色系。
- 實作：原生 HTML、CSS、SVG、JavaScript，沒有框架或第三方圖表庫。
- 唯一網路資源：Google Fonts 的 Inter 與 Noto Sans TC。無網路時會回退到系統 sans-serif 字體，圖表功能不受影響。
- 目前最小圖寬為 1700px；外層容器負責橫向滑動。
- 頁面在窄視窗中已壓縮垂直高度，使標題、計數器、圖表和圖例可同屏閱讀。

## 7. 更新資料的方法

1. 在 CSV 中更新年度資料，保持現有三欄格式。
2. 按年份彙整；同年度並列日期以 `、` 連接。
3. 更新 `index.html` 內的 `DATA` 常數。
4. 重新檢查：年度點數、創紀錄點、缺失年份斷線、標題中的首尾紀錄值。
5. 至少測試 1926、2026 兩端，以及一個含多個並列日期的年份。

## 9. 交付注意事項

- 不要把 Y 軸改成從 0 起，否則百年間的細微變化會難以閱讀。
- 若修改 `index.html` 的 ID，必須同步修改 JavaScript 查找元素的名稱。
- 若網站使用嚴格 Content Security Policy，請把內嵌 CSS／JavaScript移至站內檔案，或按該網站的 CSP 規則加入 nonce；不要直接放寬整站安全策略。
- 若公開分發，建議標註圖表 skill 開發者「躺在廢墟里」。
