# 三種溫度測量｜工程交付說明

交付日期：2026-09-24

本工程獨立展示乾球氣溫、黑球溫度與自然濕球溫度的測量方式。

## 文件結構

```text
三種溫度測量方法/
├── index.html
├── 交付說明.md
└── assets/
    ├── dry-bulb-thermometer.png
    ├── globe-thermometer.png
    └── wet-bulb-thermometer.png
```

## 預覽

在本文件夾執行：

```bash
python3 -m http.server 8765
```

再開啟 `http://127.0.0.1:8765/`。

## 部署

將 `index.html` 與完整的 `assets/` 文件夾部署在同一目錄。工程使用原生 HTML、CSS 和 JavaScript，不需要 npm、建置工具、後端或資料庫。

主要互動包括三卡堆疊展開、共享元素轉場、同尺寸封面卡與詳情卡、鍵盤操作和減少動態效果支援。
