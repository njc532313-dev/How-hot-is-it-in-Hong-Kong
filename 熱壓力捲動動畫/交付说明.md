# 热压力滚动动画｜交付说明

## 如何打开

双击本文件夹中的 `index.html`，用浏览器打开。向下滚动可依次查看汗水蒸发、高湿度、空气温度、太阳辐射、风、身体活动与热压力；往上滚动可倒退动画。无需安装软件或启动本地服务器。

## 文件内容

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面、SVG 图解与滚动动画代码 |
| `person-cartoon.png` | 透明背景的手绘卡通人物 |
| `vendor/gsap.min.js` | 本地 GSAP 动画库 |
| `vendor/ScrollTrigger.min.js` | 本地滚动控制插件 |

移动或分享时，请复制整个文件夹，保留上述文件的相对位置。页面引用的图片与脚本都在文件夹内，可离线打开。

## 阅读与使用

- 手机会放大中央人物，并在画面下方显示当前因素。
- 系统开启“减少动态效果”时，页面改为完整静态图解。
- 箭头方向表示热量输入、散出或体内产热；空气温度与风的作用取决于当时环境。
- 此图用于解释热压力，不是个人健康诊断或风险测量工具。
